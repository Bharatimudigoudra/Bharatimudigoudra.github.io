## Ask Bharati chat

The portfolio has an automated chat ("Ask Bharati") that answers questions about my projects, skills and experience from prepared text and my public GitHub code. It is not a live person and it does not use an AI model.

- Code: `ask-bharati/` (see `ask-bharati/README.md`). The page loads it with one script tag in `index.html`.
- Visitors give an email first (format check only, not verified). Chat history is emailed to me through Web3Forms, never stored in this repo.
- GitHub evidence links are refreshed by hand: `python ask-bharati/tools/refresh_github_evidence.py`. There is no automatic sync.
- Resume: `assets/resume/Bharati_Mudigoudra_Resume.pdf` (FlowCV export, replaced by hand).
- Page styles: `assets/css/style.css`.
