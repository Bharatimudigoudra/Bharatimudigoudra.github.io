ZeroQueue - AI Gift-Card Support Copilot

Built for the HiDevs YC Fall 2026 "Moss Zero-Latency Builder Sprint"

An AI support copilot for gift-card help desks. Customers ask in plain language or upload a voucher screenshot, and the app answers only from a grounded knowledge base of 100 brands, with citations and a confidence score. When the knowledge base has no real answer, it hands the chat to a human through Intercom instead of guessing.

  • Python + FastAPI backend with a RAG pipeline over a 100-brand knowledge base indexed in Moss (minilm embeddings, hybrid search)
  • Voucher screenshot upload with Tesseract OCR, and clarifying questions for unclear requests
  • Human handoff through the Intercom REST API, with agent replies shown live in the chat
  • One Docker container, deployed on Render, with a pytest test suite
